# Portafolio Web

Portafolio estático y responsivo. Puedes abrir `index.html` directamente o usar un servidor local. Los proyectos se cargan desde `data/projects.json` y hay una copia de respaldo para la vista directa.

Antes de publicar, cambia el correo de destino en `js/app.js` y actualiza el contenido de `data/projects.json` con tus proyectos reales.
